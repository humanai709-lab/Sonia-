# Digital Marketing Project 2 — SEO Basics & Keyword Research

## 📌 Project Overview
This repository contains the complete execution and documentation for **Project 2: SEO Basics & Keyword Research**, completed as part of the **DecodeLabs Industrial Training Kit (Batch 2026)**.

The primary objective of this project is to shift from a Push Strategy (Social Media) to an Inbound Pull Strategy (SEO) by identifying high-intent, low-competition keywords for `DecodeLabs`.

---

## 🎯 Key Objectives & Deliverables
- **Search Intent Analysis:** Categorizing keywords into Informational, Navigational, Commercial, and Transactional archetypes.
- **Keyword Golden Ratio (KGR):** Calculating KGR scores (`allintitle / Monthly Volume`) to target queries with KGR < 0.25 for rapid ranking.
- **Target Domain Strategy:** Focus on 2026 tech domains including Python, SQL, Data Science, AI/ML, and Full-Stack Development.
- **20 Verified Keywords Deliverable:** Structured research dataset for content mapping.

---

## 🛠️ Research Methodology & Tools
1. **Brainstorming:** Identifying core seed technical terms.
2. **Alphabet Soup Method:** Using Google Autocomplete for real-time long-tail variations.
3. **Volume Validation:** Using Google Keyword Planner / Ubersuggest.
4. **KGR Validation:** Using `allintitle:` search operator.
5. **Intent Mapping:** Assigning content types (Blog, Landing Page, Comparison Guide).
